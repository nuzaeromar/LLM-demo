# LLM Demo: Fine-Tuning Language Models with Transformers

This repository contains a hands-on demo showing how to fine-tune large language models (LLMs)  
using the 🤗 Hugging Face **Transformers** and **Datasets** libraries.

It covers both:
- **Causal Language Modeling (CLM)**
- **Masked Language Modeling (MLM)**

with clear, step-by-step preprocessing, training, and evaluation workflows.
